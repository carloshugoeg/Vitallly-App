# Imagenes del manual de usuario

Coloca aqui las capturas usadas por `src/app/manual/page.tsx`.

## Dimension recomendada

- Recomendado: `1600x900` o `1440x810` en formato PNG.
- Tambien funcionan capturas mas grandes, por ejemplo `1920x1080`.
- El manual las muestra automaticamente en un marco `16:9`, recortando con enfoque superior (`object-fit: cover; object-position: top`) para mantener un estilo mas minimalista.
- Evita capturas verticales muy angostas, porque el recorte horizontal puede ocultar informacion importante.
